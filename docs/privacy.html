Política de Privacidade

Aplicativo: Postador Pedro · Atualizada em 1 de agosto de 2026

Este aplicativo é uma ferramenta de uso pessoal, criada para publicar vídeos automaticamente em Páginas do Facebook administradas pelo próprio autor. Ele não é oferecido a terceiros e não possui base de usuários.

Quais dados são usados

  • Token de acesso do administrador das Páginas, obtido pelo Login do Facebook, usado apenas para publicar conteúdo nas Páginas autorizadas.
  • Identificador e nome das Páginas administradas, para saber onde publicar.
  • Arquivos de vídeo guardados em armazenamento em nuvem particular do autor, enviados às Páginas no momento da publicação.

O que não é coletado

  • Dados de seguidores, mensagens, comentários ou qualquer informação de terceiros.
  • Dados de outros usuários do Facebook.
  • Informações de pagamento ou dados sensíveis.

Onde as informações ficam

Os tokens são guardados criptografados como secrets do repositório no GitHub e como variáveis de ambiente locais. Não são compartilhados, vendidos ou transmitidos a terceiros. O registro do que foi publicado guarda apenas nome de arquivo, horário e identificador do post.

Retenção e exclusão

Os dados existem apenas enquanto o aplicativo é usado. Para revogar o acesso a qualquer momento, remova o aplicativo em Facebook → Configurações → Aplicativos e sites; os tokens deixam de funcionar imediatamente. Para solicitar exclusão de dados, use o contato abaixo.

Serviços utilizados

  • API Graph do Facebook — publicação nas Páginas.
  • GitHub Actions — execução automática nos horários definidos.
  • Microsoft OneDrive — origem dos arquivos de vídeo.
